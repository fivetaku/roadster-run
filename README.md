# VOLT ROADSTER

8-bit side-scrolling fan game starring a pixel roadster. 2 worlds × 4 courses — desert highway, underground garage, neon skyway and the gigafactory boss — each with its own original chiptune. Grab the lightning from the ? block to charge up, double-jump for a barrel roll, reach the charge station.

Play: https://roadster.tesduo.com

- Arrows / A·D move, Z / Space jump (press again in the air for a barrel roll), X walk (running is the default), M mute
- `?level=2-3` starts at a course, `?autoplay=1` runs the demo bot

All art and sound are original and generated in code. Fan project — not affiliated with Tesla or Nintendo.
